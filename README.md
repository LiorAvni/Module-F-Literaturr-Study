# Module F Literature Study Hub

A static website for studying four Module F literature pieces:

- A Summer's Reading
- Mr. Know-All
- The Road Not Taken
- Rules of the Game

## How to publish on GitHub + Vercel

1. Extract the ZIP file.
2. Upload all files in this folder to a new GitHub repository.
3. In Vercel, create a new project from that GitHub repository.
4. Keep the default settings. This is a static website and does not need a build command.
5. Deploy.

## Files

- `index.html` - main website shell
- `styles.css` - UI design and responsive layout
- `app.js` - content, routing, navigation, search, accordions, theme toggle

## Copyright note

The site includes full study summaries, analysis, and the question pools. It does not reproduce the full copyrighted original stories for A Summer's Reading, Rules of the Game, or Mr. Know-All. The Road Not Taken is included as a public-domain poem.

If you have permission to publish the full text of a copyrighted story online, you can add it in `app.js` by replacing the placeholder in the relevant piece object.
