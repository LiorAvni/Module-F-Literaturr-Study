# Module F Literature Study Hub

Static website for GitHub + Vercel.

## Deploy
1. Upload these files to a GitHub repository.
2. Import the repository in Vercel.
3. Deploy as a static site. No build command is needed.

## Files
- `index.html`
- `styles.css`
- `app.js`

The public build includes study material, analysis, question pools, and the public-domain poem text. Story text pages are kept as clean placeholders so the site does not republish copyrighted stories online.
